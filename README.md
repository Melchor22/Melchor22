## 🚀 Professional Experience

### Full-Stack Software Developer — Audi México

**Project: Runtrack | February 2025 – August 2025**

Developed and deployed a web application to improve the location and traceability of Siemens electrical test devices within an industrial environment.

- Designed and implemented three REST APIs in Python for data ingestion, client access, and administrative CRUD operations.
- Developed a Wi-Fi RSSI-based positioning approach using access point information and physical coordinates.
- Evaluated positioning strategies through accuracy tests; the full-network scanning method achieved a mean error of **9.93 meters** in the tests conducted.
- Built an interactive web interface using HTML, CSS, and JavaScript, including facility maps, device searches, position tracking, and reporting.
- Deployed the APIs and web application on Windows Server using IIS.
- Prepared technical documentation and configured communication between application components.
